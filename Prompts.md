# Prompts.md — Sprint 4

## 1. Project Planning

Prompt:
"Design a beginner-friendly AI Cover Letter Generator using React.js, CSS, Node.js, Express, and Google Gemini API. Include a template-based fallback, secure backend, and optional PDF resume parsing."

## 2. UI Development

Prompt:
"Create a modern, responsive SaaS interface for an AI Cover Letter Generator using React.js and CSS. Include candidate details, job role, company name, skills, experience, resume PDF upload, loading feedback, generated letter preview, copy button, and download button. Keep the design clean and the code simple."

## 3. Backend Development

Prompt:
"Build an Express API endpoint that validates candidate details, accepts a PDF using Multer, extracts PDF text with pdf-parse, and generates a professional cover letter using the Google GenAI JavaScript SDK. Keep the API key secure using environment variables."

## 4. Prompt Engineering

Prompt:
"Generate a professional cover letter using the candidate's name, skills, job role, company, experience, and uploaded resume text. Use only the supplied information. Never invent qualifications, achievements, or work experience. Return a concise cover letter with proper greeting, closing, and separate paragraphs."

## 5. Security Review

Prompt:
"Review this React and Node.js project for exposed API keys, unsafe PDF uploads, missing input validation, oversized file uploads, and error handling. Suggest simple and beginner-friendly security improvements."

## 6. Testing

Prompt:
"Prepare test cases for valid form submissions, missing fields, invalid PDFs, oversized files, missing Gemini API keys, API failures, slow AI responses, resume text extraction, streaming generation, copy-to-clipboard, and text downloads."

## Learning Note

I used AI assistance to plan the interface, understand React and API integration, develop effective prompts, and identify testing scenarios. I tested the project as part of my learning process.
